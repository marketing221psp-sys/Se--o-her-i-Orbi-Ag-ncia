# ORBI CLIENT BRIEF FORMAT
Preencher (ou responder "NENHUMA/NÃO SEI" onde aplicável — o engine decide o resto).

```
CLIENTE:
NICHO:
PÚBLICO:
OBJETIVO:
SERVIÇOS:
POSICIONAMENTO:
PERSONALIDADE:
CORES:            (ou "nenhuma — decidir pelo posicionamento")
IMAGENS:          (fotos reais disponíveis? ou "nenhuma — usar Image Direction/stock")
CTA:
PÁGINAS:
REFERÊNCIAS:      (aceita "NENHUMA")
```

## Regra
`REFERÊNCIAS: NENHUMA` é uma resposta válida e esperada — o ORBI SITE ENGINE deve produzir direção visual completa (ORBI-DESIGN-ENGINE) só com as linhas acima. Campos em branco são decididos automaticamente a partir de NICHO+PÚBLICO+POSICIONAMENTO+PERSONALIDADE.
